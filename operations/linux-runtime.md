# Linux 執行環境與診斷

> 來源：[舊 Linux 筆記](../TOOLS_NOTE/作業系統/Linux%20note)。內容偏向 Linux／systemd 環境，請確認目標系統實際配置。

## 使用者執行期目錄

`/run/user/<UID>` 通常由登入／session 管理機制維護，供該使用者的執行期資料使用。不要將需永久保存的資料放在此處，也不要假設它在所有無登入背景服務情境下都存在。

## 手冊與命令

`man` 手冊依章節分類，例如第 1 節為一般命令、第 2 節為系統呼叫、第 3 節為函式庫介面、第 5 節為檔案格式、第 8 節常見系統管理命令。

```bash
man 5 passwd
command -v python3
```

## 程序、動態連結與資源排查

| 工具 | 主要用途 |
| --- | --- |
| `readelf` | 檢視 ELF 標頭、節區及動態資訊 |
| `ldd` | 顯示程式的動態函式庫相依資訊；不要對不可信的執行檔隨意執行 |
| `nm`、`objdump` | 檢視符號與物件檔資訊 |
| `fuser` | 查詢使用檔案或掛載點的程序 |
| `timedatectl` | 在支援的系統查詢時間與同步狀態 |
