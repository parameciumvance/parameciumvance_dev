# 日誌管理

涵蓋日誌產生、格式、收集、傳輸、輪替、保存、集中查詢與診斷。不以特定工具或技術堆疊作為領域分類。

## 日誌設計注意事項

使用 logging 等檔案輸出時，應先建立所需目錄並驗證權限。規劃輪替、清理、容量及保存期限，避免磁碟耗盡。舊 SOP 建議 ELK 供集中搜尋，依規模選用。
