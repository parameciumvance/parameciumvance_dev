# ParameciumVance Development Knowledge Base

個人軟體工程知識庫：整理可重複使用的工程方法、技術筆記、問題排解與範例。

## 領域導覽

- [開發](development/README.md)：依任務／知識領域分層，深度不固定。
- [系統運作與維護](operations/README.md)：程序、日誌與運行環境。
- [網路通訊](networking/README.md)：連線診斷與通訊相關工程任務。
- [工具與故障索引](indexes/README.md)：跨領域查詢入口。

## 既有入口

- [工程指南](guides/README.md)：目前採用的開發方法與原則
- [規格指南](sdd/specification-guide.md)：目前正式的規格制度（原路徑保留）
- [技術筆記](notes/README.md)：技術概念、工具與平台的學習紀錄
- [問題排解](troubleshooting/README.md)：症狀、原因、診斷與解法
- [範例](examples/README.md)：可執行或可重用的最小範例
- [待整理](inbox/README.md)：尚未驗證或分類的資訊
- [封存](archive/)：過時但有歷史參考價值的資料

## 知識生命週期

收集至 inbox → 按任務／知識領域整理、驗證與維護；文件類型（notes、guides、troubleshooting）是屬性，不強制決定目錄位置。過時內容移入 archive，並保留必要背景。

## 舊資料

舊目錄 `TOOLS_NOTE/`、`開發/`、`範例/`、`開發日誌/`、`history/` 與根目錄的 `TROUBLESHOOT`、`系統重設SOP`、`README` 暫時保留原樣，後續按需逐步遷移。舊資料不代表現行建議，使用前請確認適用版本。

## 維護方式

詳見 [知識庫維護指南](guides/knowledge-base-maintenance.md)。既有文件持續增量整理；舊資料保留原位。
