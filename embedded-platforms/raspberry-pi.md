# Raspberry Pi：主控台與電源故障

## 序列主控台

舊筆記使用 USB 序列轉接器與 PuTTY 查看開機日誌。須確認 UART 電壓、接線、baud rate 與 console 設定。

歷史主機 udev 規則 /etc/udev/rules.d/70-ttyusb.rules：

```udev
KERNEL=="ttyUSB[0-9]*", MODE="0666"
```

此規則讓所有本機使用者可讀寫符合裝置，不建議作為預設；優先使用適當群組（如 dialout）及最小權限。規則應設在連接轉接器的主機。
