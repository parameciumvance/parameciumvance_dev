# K210：Kendryte SDK 移植至 Maixduino

歷史移植觀察（版本未記錄、未重驗）：Maixduino SDK 缺少 iomem.h，當時不支援 nncase 0.2（kmodel v4）。須依實際 SDK 與模型工具鏈版本確認。

C 轉 C++ 時注意 template 為保留字；例如 void* 到具體指標不能如 C 一般隱式轉換（非所有指標轉換都禁止）；C 函式庫需確認 extern "C" linkage。
