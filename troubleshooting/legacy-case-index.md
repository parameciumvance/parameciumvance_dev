# 歷史故障案例索引

> 來源：[舊 TROUBLESHOOT](../TROUBLESHOOT)。以下為原始經驗的主題索引；**未重新驗證**。遇到問題時應先確認實際環境與版本。

| 主題 | 舊筆記提到的現象與線索 | 狀態 |
| --- | --- | --- |
| C++ 執行期 | 空指標、錯誤位址、未回傳值、std::array 初始化與崩潰 | 待逐案驗證 |
| Python / Matplotlib | 舊版 `pause` 相關崩潰；原筆記附上游修正連結 | 版本特定 |

| OpenCV / C++ | undefined symbol、標頭／函式庫不一致、連結參數 | 待逐案驗證 |
| Conda / pip | shell alias 可能覆蓋環境中的 pip | 可依執行路徑排查 |

| Ubuntu 套件管理 | 建議依賴意外帶入桌面套件、套件版本衝突 | 版本特定 |

## 使用原則

此索引只協助找到歷史案例，不把相關性當成因果性。若重新確認問題與解法，再新增獨立案例文件，記錄症狀、環境、證據、根因與修復方式，並回鏈此索引。
